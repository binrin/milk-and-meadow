# 짜요짜요 타이쿤 · 우리 목장

원작 자료를 참고한 비공식 터치 목장 게임입니다. 새 일러스트로 꾸민 v3.0.0입니다.
원작의 모든 규칙과 수치를 동일하게 복원한 버전은 아닙니다.

## 아이폰에서 시작하기
https://binrin.github.io/milk-and-meadow/ 를 Safari로 열고 공유 → 홈 화면에 추가를 선택하세요.
처음에는 인터넷이 필요하며, 오프라인 준비 완료 후 인터넷 없이 플레이할 수 있습니다.

## 업데이트
설정에서 최신 버전 업데이트를 선택하세요. 버튼이 보이지 않는 이전 버전은
https://binrin.github.io/milk-and-meadow/update.html 을 열면 됩니다.
업데이트는 기존 저장을 지우지 않습니다.

## 조작과 저장
기본 화면은 원작 자료를 바탕으로 재구성한 클래식 모드입니다.
1–9번 젖소를 터치하고 착유·총·치료·스팀팩 도구를 바꾸며 작업합니다.
0번 우유통으로 저장고에 옮긴 뒤 상인에게 신선도와 흥정을 고려해 판매합니다.
공장에서는 6종 유제품을 만들고, 애완소 육성 및 게임 속 주식 거래도 즐길 수 있습니다.
진행은 이 기기 브라우저에 저장됩니다. 기기 변경이나 Safari 데이터 삭제 전 설정에서 저장 백업을 받으세요.
클래식 모드는 별도 저장 키를 사용하므로 기존 우리 목장 저장을 덮어쓰지 않습니다.
기존 확장 목장과 그 저장은 [기존 우리 목장](./expanded.html)에서 계속 사용할 수 있습니다.
클래식 모드와 기존 확장 목장의 저장은 서로 독립적입니다.

## 제작과 라이선스
원작 개발사 엠조이넷. 비공식 재구성이며 원작 실행 파일을 배포하지 않습니다.
새 게임 코드와 생성형 일러스트를 사용합니다. 분석 근거와 미확인 범위는 작업공간 analysis에 기록합니다.
