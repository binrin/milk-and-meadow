# 우리 목장 · Milk & Meadow

에너지·체력 제한 없이 즐기는 개인용 2D 솔로 목장 게임입니다.

## iPhone 설치
Safari에서 GitHub Pages 주소를 열고 **공유 → 홈 화면에 추가 → 웹 앱으로 열기**를 선택하세요. 홈 화면 아이콘으로 처음 실행한 뒤 설정에서 오프라인 준비 완료를 확인하세요. 처음에는 인터넷이 필요합니다.

## 플레이
움직이는 젖소를 직접 터치 → 급여/착유 → 착유통 회수 → 출하. 착유기를 선택하고 소에 직접 장착할 수 있습니다. 플레이 중 약 8분마다 하루가 흐르며 앱을 닫으면 시간이 멈춥니다. 하루를 일찍 마무리할 수도 있습니다. 돈이 없으면 무료 풀 베기와 일손 돕기를 반복할 수 있습니다. 품종별 생산, 출산/송아지 성장, 시설 확장, 자동 급여/착유/판매, 연구, 반복 장기 계약이 포함됩니다. 모든 아이템은 게임에서 번 골드로 구매합니다. 모든 시설과 분원은 최대 Lv.10, 3개 추가 목장 매입·확장·소 이동, 가상 주식 4종, 반복 전국 사업을 제공합니다.

## 저장
이 기기·이 주소의 브라우저 저장소에 자동 저장됩니다. Safari 데이터 삭제 또는 기기 변경 전 게임 설정에서 JSON 백업을 내보내세요. 복구 시 덮어쓰기 확인이 있습니다. 서버에 세이브를 전송하지 않습니다.

## 제작 범위
원작에서 영감을 받은 새로운 코드와 생성형 2D 이미지를 사용합니다. 실제 낙농에서 착안했으나 품종 수치, 성장 기간과 품질 규칙은 게임용으로 단순화했습니다. 원작의 모든 기능을 동일하게 복원한 버전은 아닙니다.

## 배포
GitHub Pages: Settings → Pages → Deploy from a branch → main / (root). 모든 경로는 상대 경로입니다. 외부 JS/CSS 의존성이 없습니다.
